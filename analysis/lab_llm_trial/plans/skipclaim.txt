PLAN: plan --skip-claimed must adopt the taken-over queue's finished parts
Edit only tools/lhe_parts.py and tests/test_lhe_parts.py (in your worktree).

CAUSE
cmd_plan with skip_claimed only adds the other queue's *claimed task names* to `known`. Parts already made
under that queue's layout (names from mg.lhe_part_paths(name, old items)) are never linked to the new layout's
names. The only linking is _adopt(D, name, its), and it reads the old layout from the NEW queue's own
specs (D["specs"]/name.json), which does not exist in a fresh queue -> returns 0. So every run is re-queued.

FIX (tools/lhe_parts.py)
1. _adopt: take the old queue's dirs as an optional argument, and read the old spec from there.
   Change the head of the function to:

   def _adopt(D, name, its, old_D=None):
       old_D = old_D or D
       sf = os.path.join(old_D["specs"], name + ".json")
       if not os.path.exists(sf):
           return 0
       old = [r for r, _ in _spec(old_D, name)]
       ... (rest unchanged: new = ..., strip, o_n/n_n, o_id/n_id, the link loop)

   Update the docstring by one line: "old_D: the queue whose parts are taken over (plan --skip-claimed)".
   Do not touch the linking loop: it already uses os.link, skips if src missing or dst exists, never deletes.

2. cmd_plan, in the per-process loop, replace
       n_adopt += _adopt(D, name, its)
   by
       n_adopt += _adopt(D, name, its)
       for q2 in getattr(a, "skip_claimed", None) or []:
           n_adopt += _adopt(D, name, its, _dirs(q2))
   It must stay BEFORE the line that writes this queue's specs/name.json and before the
   `os.path.exists(part)` test in the k-loop (it is already above both). The `exclude` check stays first.
   (Own-queue adoption first, then each taken-over queue; the os.path.exists(part) guard in _adopt makes
   a second source a no-op once a part is linked.)

   Result: a linked part exists at the new path, so `if os.path.exists(part) or tag in known` counts it
   as present and it is not written to todo/.

3. Update the help text of --skip-claimed in main():
   "queues whose claimed runs are not planned again and whose finished parts are linked to this layout".
   Also the module docstring line 16 (same words, short).
