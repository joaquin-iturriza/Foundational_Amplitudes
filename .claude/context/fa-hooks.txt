---
- A hook refuses the end of a turn only for an omission the turn itself can clear; what waits on an agent, a job, a
  cluster or the user is a note in its output.
- Every registered hook runs through `.claude/hooks/dispatch.py <hook>`: it skips a hook listed in
  `.claude/hooks/disabled.json`; it detects a loop (the same refusal fingerprint twice with nothing changed in between:
  no tool call, the same HEAD, plan and open events), then disables that hook, opens an incident and lets the call
  through.
- Incidents: `tools/hook_incident.py <hook> --why` (or the dispatcher's loop detector) disables the hook, appends
  to `.claude/hooks/incidents.jsonl` and opens an ALERT; a fix is tested on the recorded refusal (`--replay <id>`;
  `--show <id>` prints it) before `--resolve <hook>` re-enables it; a call that is Joaquin's goes as `site ack E<n>
  --needs-user "<what>"`.
- The set. Stop: `plan_check.py`, the single gate (plan and owners, events, supervisor and waiter, questions sent,
  claims, figure pairs, context flush, reply answers), and `auto_push.sh` (pushes, never
  refuses). PreToolUse: `submit_guard.py` (placement, design, HP grids, plotting off in a submitted script, GPU budget,
  wall-time target), `git_verify_guard.py` (claims check bypasses, attribution in a commit message), `review_guard.py`
  (reviewer locks, one reviewer per backlog), `brief_guard.py` (briefs), `plan_files_guard.py`, `md_guard.sh`,
  `plot_guard.sh` (config writes), `worktree_guard.sh` (advisory), `worktree_fold_guard.sh`, `review_backlog.sh
  gate|bashpre`, `hook_syntax_guard.py`, `no_blocking_question.sh`, `send_check.py`, and the user-level
  `sleep_guard.sh`. PostToolUse: `review_guard.py` (records reviewer ids), `owner_context.py` (context after a
  hand-back), `delegation_note.py` (a note, never a refusal, when the main session edits code, runs an analysis or
  tests, or submits; counted in `site digest`), `context_push.py`, `context_guard.py`, `hook_syntax_guard.py`. SessionStart and PreCompact:
  `context_guard.py`, `context_push.py`, the user-level `ledger_guard.sh session-start`. `.githooks/commit-msg` refuses
  attribution lines in every commit.
- Python hooks exit 1 on a crash (non-blocking); shell hooks are parsed before a write and restored from the last good
  copy after one.
- Tests: `tests/test_setup_scenarios.py` and `tests/test_hooks_real.py` over the recorded states in
  `tests/fixtures/hooks_20261029/`. A registration change goes in with the fix it completes when Joaquin asked for that fix [D280], shown to him as the
  diff `tools/switch_settings.py` prints; any other registration change goes to him as that diff first.
- A new doc Joaquin approved goes in `.claude/md_allowlist.txt`; a single-format figure he accepts goes in
  `.claude/figure_pair_ignore.txt`.
- Clean-up permission rules match the bare command only: `bash scripts/prune_site.sh <site>`,
  `site run <site> FA -- python sweep/prune.py ...`, `site run <site> FA -- python tools/prune_copies.py ...` (any
  `site run` flags before the site are fine). A `cd ...;` or `timeout` prefix, a pipe, a `;` or `&&` chain, or `rm`
  inside the remote command falls to the auto-mode classifier, which refuses deletions (2026-11-11/12: the main
  session's first prune and the owner's mmap-cache `rm`). Run the bare form, alone in its call.
