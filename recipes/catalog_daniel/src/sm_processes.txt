# ============================================================================
# Standard Model (sm) Tree-Level Partonic Subprocesses (2→1, 2→2, and 2→3)
# ============================================================================
#
# Format:
#   2→1:  initial1 initial2 > [mediators] > final                  # description
#   2→2:  initial1 initial2 > [mediators] > final1 final2           # description
#
# Particle naming follows MadGraph conventions:
#   quarks:    u, d, s, c, b, t  (antiquarks: u~, d~, s~, c~, b~, t~)
#   leptons:   e-, mu-, ta-      (antileptons: e+, mu+, ta+)
#   neutrinos: ve, vm, vt        (anti: ve~, vm~, vt~)
#   bosons:    g, a, z, w+, w-, h
#
# [mediators] lists ALL virtual particles that can appear internally
# in any tree-level Feynman diagram for that process (union of QCD and EW).
# A "-" denotes a contact interaction (no intermediate particle).
# Mediator names always use the particle (not antiparticle): e.g., [u] not [u~].
#
# Comments are short process identifiers using Unicode:
#   antiparticles: ū, d̄, s̄, c̄, b̄, t̄
#   charges/symbols: W⁺, W⁻, e⁻, e⁺, μ⁻, μ⁺, τ⁻, τ⁺, H, γ
#
# Initial states: only proton constituents (g, u, u~, d, d~, s, s~, c, c~, b, b~).
#
# Model: sm (restrict_default.dat)
#   - Diagonal CKM matrix (no cross-generation W couplings)
#   - Zero Yukawa couplings for u, d, s, c, e, mu (no Higgs coupling)
#   - Massless u, d, s, c, e, mu
# ============================================================================
